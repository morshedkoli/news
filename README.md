# 📰 News Central — Digital News & Content Publishing Admin

[![Next.js](https://img.shields.io/badge/Platform-Web_Application-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/Language-TypeScript_|_JavaScript-blue?style=for-the-badge)](https://www.typescriptlang.org/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

A comprehensive content management and editorial control platform for regional digital news agencies, featuring article drafting, multimedia embedding, category indexing, and SEO meta configuration.

---

## 🌟 Key Features

- **Editorial Dashboard**: Draft, edit, review, and publish articles with rich text formatting.
- **Category & Tag Hierarchy**: Organize articles under hierarchical topic channels with custom slugs.
- **SEO & Social Cards**: Automated OpenGraph metadata generation for rich social media sharing.

---

## 🛠️ Technology Stack

- **Platform**: Next.js, React
- **Database**: PostgreSQL / Prisma

---

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/morshedkoli/newscentral.git

# 2. Install dependencies
npm install

# 3. Launch application
npm run dev
```
